Chess engine for the make.fun tiny-chess-01 bounty: one `main.py`, under 4 KB,
Python 3.13 standard library only.

Mailbox board, PVS alpha-beta with a transposition table, null move, LMR,
killer moves and a capture quiescence search, all under a fixed node budget
(no clock, no randomness), so replays match.
